# Kerala Botaniq

Discover, learn and identify the beautiful plants and trees of Kerala, India.

## Features

- Search and browse plants from Kerala (GBIF data)
- Identify plants by uploading an image (Pl@ntNet API)
- Minimal, nature-inspired design

## Tech Stack

- React.js
- GBIF API
- Pl@ntNet API
- Tailwind CSS or custom CSS

## Getting Started

1. Clone the repo
2. Install dependencies: `npm install`
3. Create a `.env` file with your Pl@ntNet API key
4. Run: `npm start`
